This application will let you :
-  Add students as users
-  Add music exercise with hyerlinks
-  Assign any exercise to any student using user friendly form

This is a Spring Boot Project with simple static HTML pages that shows:
- CRUD application for 3 relational tables
- Duplicate data Validation
- Invalid input data validation
- Dynamic Listing of records in table

To use it you need:
-  Docker
-  Java 21 or higher

How to install:
-  clone the project
-  open project folder with IDE
-  Run the project

How to access the Pages:
- localhost:8080/index -> User registration page
- localhost:8080/exercise -> Exercise record adding page
- localhost:8080/tracker -> Lesson assigning page
